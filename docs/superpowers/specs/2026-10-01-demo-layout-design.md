# 데모 섹션 가운데 정렬 · 배경 없음 (계획 9-2, 2026-10-01)

시안: `docs/superpowers/mockups/2026-10-01/demo-layout.html` — 세 안(A 플립 안내판 / **B 미니멀 가운데** / C 계기판) 중 **B**.

## 사용자 결정 (2026-10-01)

1. 왼쪽 정렬 → **가운데 정렬**
2. **배경 없음**: 데모 뒤 3D에는 점이 하나도 보이지 않는다(지형 점 없음). 3D가 꺼진 화면(움직임 줄이기 등)에서도 데모 뒤 대체 이미지 없음
3. 배치는 **시안 B "미니멀 가운데"**: 지금 요소를 그대로 두고 가운데 축 한 줄로 쌓는다. 결과 카드의 테두리·바탕을 없앤다
4. 문구는 임시 — 사용자가 나중에 다시 쓴다(이번에는 문구를 바꾸지 않음)

## 구조 (위에서 아래, 모두 가운데)

| 요소 | 너비 |
|---|---|
| 머리표 `DEMO` → 제목(h2) | 섹션 폭(최대 1080px) |
| 설명·기준 문단 | ≤ 620px |
| 질문 문장(노선·등급·출발일 선택지가 문장 안에) | 데모 열(≤ 880px) |
| 출발일 막대 + 양 끝 날짜 + 공휴일 이름표 + 범례 | ≤ 880px |
| 큰 예측가(IBM Plex Mono, 플립) | 글자 크기 `clamp(2.25rem, 6vw, 3.5rem)` |
| 80% 구간 띠 + 낮은 값 / 이름 / 높은 값 | ≤ 520px |
| 추천 배지(DROP EXPECTED 등) | 글자 폭 |
| 이유 · 확신도(WAIT/DROP일 때만) | ≤ 560px |
| "미리 계산된 예측 · 기준일" | 글자 폭 |

- 가운데 정렬 글은 마지막 줄에 한 토막만 남으면 눈에 띄어 `word-break: keep-all` + `text-wrap: balance`. 일본어는 `auto-phrase`(머리말 제목과 같은 이유 — keep-all이면 휴대폰 폭을 넘친다)
- 3D가 켜졌을 때 왼쪽 글 섹션에 걸던 560px 줄 너비 규칙에서 `#demo`를 뺐다 — 3D 켜짐·꺼짐 모두 같은 배치(CLS 없음)
- 기능·조작은 그대로: 문장 선택지, 막대 누르기·끌기·←/→/Home/End(슬라이더 역할), 조작 멈춘 뒤 한 번 알림(aria-live), 불러오기 실패 → 안내 + 다시 시도, 공휴일 ◆·이름표, `noscript` 안내, 섹션 근처에서 데이터 불러오기

## 3D 장면

- `src/three/scenes.ts`의 `demo` 장면을 `dim: 0`, `noise: 0`으로 — 셰이더가 지형·지도 점 알파에 `uDim`을 곱하므로 모든 점이 투명해진다
- 장면을 아예 빼지 않은 이유: 활성 장면이 없는 틈이면 `pickScene`이 null을 돌려 앞 장면(⑤ 한계 지형)이 그대로 남는다
- 카메라는 연락처와 같은 자리(`[-5, 16, 30]`, 세로 화면 override도 같음) — 데모 → 연락처는 카메라가 움직이지 않고 점만 서서히 떠오른다. ⑤ → 데모는 `uDim`이 감쇠(damp)로 천천히 0이 된다(번쩍임 없음)
- 3D 꺼짐: 데모 섹션에는 원래 `ChapterFigure`(대체 이미지)가 없다. 바탕은 페이지 공통 그라데이션뿐

## 접근성

- axe(세 언어) 위반 없음 그대로. 배지는 보이는 영어 + 언어별 낭독 문구 그대로
- 판이 없어도 뒤에 점이 없으므로 글 대비는 바탕색 기준(본문 `--tx`, 흐린 글 `--mute` ≥ 4.5:1)

## 테스트

- 단위(`three-scenes.test.ts`): 데모 `dim 0`·`noise 0`, 카메라·목표점이 연락처와 같다(가로·세로 화면)
- e2e(`demo.spec.ts`): 1440 폭에서 제목·질문·기준일(글자 폭)과 예측가·배지(상자) 가운데가 섹션 가운데 ±4px, 막대 ≤ 880·띠 ≤ 520이 가운데, 결과 칸 테두리 0·바탕 투명 / 3D 켜짐에서 `data-active-scene="demo"` + 데모 열 오른쪽 빈자리 화소의 최대 채널 ≤ 48(옛 장면 dim 0.45는 169로 실패하는 것을 확인) / 320·390 폭 세 언어 가로 넘침 없음

- 바뀐 파일: `src/three/scenes.ts`(demo 장면), `src/styles/globals.css`(데모 블록·560px 규칙에서 `#demo` 제외), `src/components/demo/DemoResult.tsx`(이유·확신도에 `demo-reason` 클래스)
