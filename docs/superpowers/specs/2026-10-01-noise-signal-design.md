# 머리말·① 배경 "잡음 → 신호" 설계 (2026-10-01, 계획 9-3)

> 사용자 승인(2026-10-01): 머리말·①의 "물결 줄"(계획 6-5 §6, 카메라 C) 배경을 **잡음 → 신호** 연출로 바꾼다.
> 시안(2D 흉내, 최종): `docs/superpowers/mockups/2026-10-01/noise-signal.html` — 단계·시간·모양의 기준.
> 바꾸는 설계: `2026-09-29-hero-project-handoff-design.md` §4·§6(① 카메라 C·물결 줄). 이륙·흩어짐 C·비행기 시계(6-6)는 그대로.

## 1. 무엇을 보여 주나

머리말 문장 "가격은 매일 흔들립니다. / 대부분은 잡음이고, 그 안에 몇 개의 신호가 있습니다."를 점으로 그대로 보여 준다.

1. 공항 불빛이 흩어진 뒤(기존 이륙·전환), 같은 점들이 화면 전체에 깔린 **잡음 밭**이 된다. 깊이가 있다(가까운 점 = 크고 밝음, 몇 개는 흰빛). 점마다 제자리에서 떨리고 은은하게 반짝인다. 첫 시안보다 잘 보이게(사용자 요청), 그래도 글은 WCAG AA.
2. 단계(머리말을 지나는 스크롤, 비행기 시계와 같은 최대 속도):
   - 단계 1 (q 0 → 0.25): 잡음만
   - 단계 2 (q 0.25 → 약 0.6): 예약 곡선 구간마다 점 하나(8개)가 **하나씩 호박색으로 켜지며** 근처 잡음 자리에서 제자리로 미끄러진다
   - 단계 3 (q 0.5 → 0.83): 그 사이를 **점으로 된 선**이 왼쪽에서 오른쪽으로 그어진다(부드러운 호박색 번짐) — "모든 것은 점" 규칙
   - 단계 4 (q 0.82 → 1): **U자 예약 곡선**이 완성되고 잡음이 약 30% 가라앉는다(떨림 70%↓, 알파 30%↓)
3. ①(`#project`)에서는 완성된 U와 잡음이 흐린 배경으로 남고(장면 `dim`), ②로 넘어가는 전환은 지금 그대로.

## 2. 데이터 — U자의 8구간

- `charts.json` `curve.mean`(D-1~3 → D-61~90, %×10)과 같은 값: 왼쪽 = 이른 구매(D-61~90 +2.1), 가운데 바닥(D-31~45 −5.0), 오른쪽 = 출발 직전(D-1~3 +11.1).
- 3D는 `charts.json`(gzip 약 40KB)을 받지 않는다. `terrain.json`에 이미 있는 남은 일수별 곡선 `curve`(dtd·pct·n — 지금은 스키마가 버림)를 받아 구간 경계 `BOOKING_BINS`로 **n 가중 평균**을 낸다. 단위 테스트가 이 값이 `charts.json` `curve.mean`(뒤집은 순서)·`bins`와 같은지 지킨다 — 숫자를 코드에 적지 않는다.

## 3. 화면 배치(순수 함수, 단위 테스트)

- 잡음 밭과 곡선은 **화면 좌표(NDC)** 로 정하고, 셰이더가 고정 카메라(`[0,0,24]` → 원점, 화각 40° = 차트 카메라)와 화면 비율(`uAspect`)로 월드 자리를 낸다 — 창 크기·세로 화면이 바뀌어도 화면을 고르게 덮는다.
- `signalLayout(aspect, bins)` → 8구간의 화면 자리(NDC)와 선을 위한 누적 호 길이(Catmull-Rom을 화면 px 비율로 잰 값):
  - 가로 화면: 글은 왼쪽(.wrap 왼쪽 열) → 곡선은 오른쪽, 가로 화면 비율 0.53 → 0.93, 세로 가운데 약 0.55(시안 0.50 → 0.94·0.56을 16:10과 글 폭에 맞춤), 1%p = 화면 높이의 1.8%.
  - 세로 화면: 글은 아래(머리말도 ①처럼 아래 정렬로 바꾼다) → 곡선은 위쪽, 가로 0.10 → 0.90, 세로 0.12(+11.1) ~ 0.33(−5.0).
- 셰이더 `curveAt(s)`는 같은 Catmull-Rom을 누적 호 길이로 따라가 선 점을 고르게 놓는다(TS `curvePoint`와 같은 식, 단위 테스트).

## 4. 점 배정(순수 함수 `buildField`)

- 잡음 밭 점 수: 데스크톱 3,400 · 세로 화면 1,300(시안 밀도 약 0.0027개/px²). 공항 불빛·비행기 점은 **모두** 넣는다(같은 점이 잡음이 된다), 남는 자리는 다른 신호 점 → 잡음 점 순서로 시드 난수로 채운다.
- 역할(`aMeta.w`, 물결 공휴일 자리를 대신 씀 — 정점 속성 16개 한계): 0 = 밭에 없음(숨김), 1 = 잡음, 2+i = 구간 점 i(0..7), 10+s = 선 점(s = 곡선 위 호 길이 비율 0..1).
- `aField`(옛 `aWave` 자리): 잡음 = (u, v, 깊이 d), 구간 점 = (곡선 자리에서 떨어진 정도 du, dv, d) — "근처 잡음 자리"에서 켜져 제자리로, 선 점 = (0, 0, 0).
- 구간 점 8개는 공항 불빛이 아닌 밭 점에서, 선 점(데스크톱 150 · 세로 100)은 밭에 없는 잡음 점에서 고른다(선이 그어지기 전에는 보이지 않는다 — 미리 U자 모양으로 점이 몰려 보이지 않게).
- 떨림·반짝임의 점마다 위상·속도는 이미 있는 흩어짐 좌표(`aScatter`)에서 뽑는다(속성 추가 없음).

## 5. 시간 — 비행기 시계를 늘린다

- 머리말에 스크롤 자리를 준다: 3D가 맨 위에서 켜졌을 때(`html.hero-runway`)만 머리말을 230svh로, 글 상자는 `position: sticky`로 화면에 붙인다(`.intro-pin`). 맨 위에서만 붙는 클래스라 보이는 글이 움직이지 않는다(CLS 0, 6-5와 같은 이유).
- 스크롤 → 진행도 p(`runwayProgress`): 0 → y0(0.9·화면) = 0 → 0.30(내려앉기), y0 → yA = 0.30 → 0.96(이륙·흩어짐·불빛 → 잡음 밭), yA → yB = 1 → `SIGNAL.end`(1.8, 잡음 → 신호), 그 뒤 1.8.
  - yA = 머리말 윗변 + 0.25·화면(글이 붙은 뒤 조금 지나서), yB = 머리말 아랫변 − 화면 높이(붙임이 풀릴 때).
- 시계는 그대로 최대 0.28/초 — 빠른 휠 한 번에 ①까지 가도 이륙(약 3.4초) → 잡음 → 신호(약 2.9초)가 이어서 나온다. 옆 목차·`#` 이동은 즉시(6-6 그대로).
- 신호 단계 q = `signalStage(p)` = (p − 1)/0.8. 셰이더는 감쇠된 p에서 q를 받는다. 장면 기본값 `plane`은 끝(1.8) — 3D가 ①에서 켜지거나 ②에서 거슬러 오면 U는 완성 상태.
- `data-signal`(q, 소수 셋째 자리)을 html에 적는다(e2e).

## 6. 그리기(셰이더, 매 프레임 JS 작업 없음)

- 장면 값 `field`(옛 `rows`)가 지형 ↔ 잡음 밭을 섞는다. `about` = 카메라 `[0,0,24]`·목표점 원점·`field 1`·`dim 0.6`(①), 머리말일 때는 `dim 1`.
- 잡음 점: 지름 (1.4 + 2.6·d)px, 알파 (0.16 + 0.38·d)·반짝임(0.75 + 0.25·sin), d > 0.85는 흰빛(#C9DBFF), 떨림 (1.6 + 1.2·d)px(화면 공간). 단계 4에서 떨림 ×0.3, 알파 ×0.7.
- 구간 점: 켜짐 L(expo.out, 0.12 동안, 점마다 0.035 늦게)에 맞춰 근처 자리 → 제자리, 색 → 밝은 호박, 크기·번짐 커짐, 번짐은 천천히 숨쉬듯(시안 pulse).
- 선 점: 그어지는 머리(q 0.5 → 0.83, 호 길이 0 → 1)가 지나면 0.03 호 길이 동안 커지며 나타난다. 핵 + 넓은 부드러운 번짐(빛 더하기에 가까운 공항 불빛 섞기를 그대로 쓴다) — 겹친 번짐이 시안의 5px 번짐 선처럼 보인다.
- 거리 흐림·잡음 배율(uNoise)·은은한 점(soft)은 밭에 쓰지 않는다. soft·`SOFT_POINT`는 지운다.

## 7. 글 읽힘

- 머리말·① 글에 어두운 글자 번짐(`text-shadow`, 시안 0 0 18px·0 0 6px `#02040a`)을 3D가 켜졌을 때만 준다. 화소 대비 검사(`terrain.spec`)가 지킨다(머리말 글이 붙은 동안 점이 지나가므로 검사 자리도 신호 단계 안).
- 가로 화면 비네트(.backdrop::after)는 그대로 — 왼쪽 글 쪽이 어둡다.

## 8. 3D 꺼짐·움직임 줄이기

- 머리말·①에는 원래 대체 이미지가 없다(`FIGURE_KEYS` = hero·problem·bubble) → 그대로 글만. `hero-runway`가 없으니 머리말도 한 화면 높이 그대로.

## 9. 성능

- 새 라이브러리 없음. 새 속성 없음(옛 `aWave`·`aMeta.w` 재사용), uniform 몇 개(`uField`·`uSig`·`uCurve[8]`·`uArc[8]`·`uHalf`·`uPxY`). 곡선 배치는 창 비율이 바뀔 때만 JS에서 다시 계산. 3D 청크 ≤ 280KB.

## 10. 범위 밖

- 문구 변경(디자인을 다 정한 뒤 한꺼번에), 가격 추세선 형태(시안의 다른 선택지).

## 구현 결과 (계획 9-3)

브랜치 `plan-9-3-signal`. 실제 GPU(헤드 있는 크로미움 화면 밖)로 1440×900(DPR 2)·390×844(DPR 3) 캡처와 모아 보기로 확인했다.

- 순수 모듈 `src/three/signal.ts`: `SIGNAL`(시계 1 → 1.8, 단계 값), `signalStage`·`binLit`·`lineHead`·`settle`, `signalLayout`(U자 화면 자리 + 누적 호 길이), `curvePoint`(셰이더 `curveAt`과 같은 Catmull-Rom), `buildField`(역할·밭 자리). `plane.ts` `runwayProgress`(yA 전 = 옛 이륙 눈금). `data.ts` `BOOKING_BINS`·`bookingBins` — 지금 데이터에서 charts.json과 최대 0.19%p 차이(일별 값이 이미 %×10 정수라서), 행 수는 정확히 같다.
- 물결 줄(`buildWave`·`WAVE`·`SOFT_POINT`, 장면 값 `rows`·`soft`)은 지웠다. 장면 값 `field`, `about` = 정면 고정 카메라 `[0,0,24]`·`dim 0.6`, 머리말은 `introScene`(dim 1). 장면 기본 `plane` = `SIGNAL.end`.
- 눈 확인에서 고친 것:
  - 선 점이 곡선 둘레 ±80px에 흩어져 선으로 안 읽혔다 — 잡음 종류 점은 `uAssemble × 0.9`만 모이는 옛 규칙 때문. 밭에 역할이 있는 점은 끝까지 모이게 했다.
  - 시안 크기·알파(지름 1.4 + 2.6·d, 알파 0.16 + 0.38·d) 그대로는 점 가장자리 흐림 때문에 잡음이 거의 안 보였다 → 지름 2.0 + 3.0·d, 알파 0.22 + 0.38·d, 밭 점 가장자리 흐림을 줄임(vEdge 0.32).
  - 번짐: 선 점 스프라이트 18px·구간 점 40px, 넓은 번짐 세기 0.55.
  - 세로 화면 U자를 위쪽 16~42% → 12~33%로(① 머리표가 화면 38% 근처라 겹쳤다).
- 시안과 다른 점: 선은 이어진 획이 아니라 점(150개, 세로 100개)이 번짐으로 겹쳐 선처럼 보인다(사이트 규칙). 단계 시간은 시계 0.8폭(최대 속도로 약 2.9초).
- 3D 꺼짐·움직임 줄이기: 대체 이미지 없음(원래 없었다), 머리말은 한 화면 높이 그대로.
