1. 첫 화면 — 밤의 공항 창가

터미널 창문으로 밤 활주로를 보는 느낌. 불빛은 모두 지금 사이트의 점(Points)과 같은 방식으로 그린다. 아래 슬라이더를 끌면 불빛이 가격 지형으로 모이는 전환을 볼 수 있다.

ML ENGINEER · 시계열 예측 · 모델 검증 · 데이터 파이프라인
활주로 가장자리(흰색) 유도로(파란색 = 사이트 데이터 점 색) 관제탑·계류장 조명(호박색 = 강조색) 경고등(아주 조금만)
제 생각: 콘셉트와 아주 잘 맞습니다. 항공권 데이터 → 공항, 플립 글자판 → 출발 안내판, 그리고 사이트 색(남색 배경·파란 점·호박색 강조)이 실제 밤 공항 불빛 색(파란 유도로등·흰 활주로등·주황 나트륨등)과 거의 같습니다. 핵심은 "불빛 = 데이터 점"으로 묶는 것입니다. 첫 화면의 불빛이 스크롤하면 그대로 가격 지형으로 모이면, 예쁜 배경이 아니라 이야기의 시작이 됩니다. 로딩 화면(LOADING 242,874 ROWS)도 "활주로 불이 앞에서 뒤로 차례로 켜지는" 연출로 바꿀 수 있습니다(위 ▶ 버튼).

조심할 점: ① 이름·직무가 1초 안에 읽혀야 하므로 불빛은 글자 뒤쪽 아래에만 둔다 ② 점 개수는 지금 지형과 같은 버퍼를 다시 쓰므로 3D 용량(240/250KB)은 거의 안 늘지만, 비행기·깜빡임은 셰이더에 조금 더해진다 ③ 대체 이미지(reduced-motion)도 이 장면으로 다시 찍어야 한다.

2. 글 뒤 검은 판 + 스크롤하면 글이 차트와 겹치는 문제

두 문제는 원인이 같습니다 — 글과 차트가 같은 자리를 나눠 쓰기 때문에 판이 필요하고, 스크롤하면 겹칩니다. 자리를 나누면 판도 필요 없어집니다. 마음에 드는 것을 눌러 주세요.

↑ 글이 올라가며 점을 덮음

지금

반투명 검은 판이 차트 위로 지나감

판이 점을 가리고, 판 가장자리에서 점이 잘려 지저분해 보인다.

글은 제자리에서 바뀜

A · 추천

자막 방식: 차트는 위, 글은 아래 고정

차트가 화면 위 60%, 글은 아래 띠에 고정되고 스크롤하면 글이 제자리에서 바뀐다(흐려졌다 나타남). 겹칠 일이 없어 판이 필요 없다. 넓은 차트(점 달력 40주)도 폭을 그대로 쓴다. 휴대폰도 같은 구조.

B

좌우 나눔: 글 왼쪽, 차트 오른쪽

데스크톱에서는 가장 흔하고 읽기 편하다. 대신 차트 폭이 절반 가까이 줄어 점 달력·구름이 빽빽해지고, 휴대폰에서는 결국 A처럼 위아래가 된다.

C

판 없이, 점이 글을 피해 흐려짐

검은 판 대신 글 주변의 점만 부드럽게 어두워진다. 가장 "몰입감" 있지만, 글이 지나가는 동안 차트 일부가 계속 흐려져 차트를 읽기 어렵다.
