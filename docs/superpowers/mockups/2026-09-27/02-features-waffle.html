③ FEATURES — 그룹 표시 시안

지금 문제: 카드 안쪽 여백이 없어 글자가 왼쪽 끝에 붙고, 공휴일 카드에만 있는 호박색 윗선이 어색함. 세 가지 방향입니다. 5-2에서 배경 점이 덩어리로 모이면, 이 부분은 덩어리 아래 라벨과 대체 화면(움직임 줄이기)에 그대로 쓰입니다.

A · RANKED LIST

순위 목록 + 점 줄 — 중요도 순으로 한 줄씩

숫자 열을 오른쪽 정렬로 맞추고, 오른쪽에 점 개수(1점 ≈ 0.5%)로 크기를 보여 줌. 공휴일은 선 대신 숫자·점 색만 호박색.

33 FEATURES

가격 하나를 예측하기 위해 넣은 것들입니다. 숫자는 모델 안에서 각 그룹이 차지한 중요도(XGBoost gain)입니다.

    B · CARDS

    정돈된 카드 — 3열, 넉넉한 안쪽 여백

    반투명 카드 + 얇은 비율 막대 + 피처 이름은 작은 태그. 공휴일은 윗선 대신 오른쪽 위 작은 HOLIDAY 표식.

    C · DOT WAFFLE

    점 와플 — 100칸 중 몇 칸

    그룹마다 점 100개 판에서 중요도만큼 켜짐. 사이트의 "점" 언어와 가장 잘 맞고, 5-2의 점 덩어리와 모양이 이어짐. 피처 이름은 마우스를 올리면(지금은 생략).
