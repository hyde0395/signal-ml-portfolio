# 계획 6-3: 첫 화면 다듬기 (배경·점·상단 바·스크롤 표시) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 본문 바탕을 첫 화면 하늘만큼 어둡게 하고, 배경 점을 차분하게(겹쳐도 안 타고 멀수록 흐림), 상단 바를 판 없는 글자 줄 + 스크롤 방향에 따라 숨김으로, 첫 화면에 `SCROLL` 표시를 더한다.

**Architecture:** 색은 `globals.css`의 토큰과 박힌 숫자만 바꾼다. 점은 한 재질을 유지한 채 미리 곱한 알파 섞기로 바꿔 점마다 "빛 더하기 정도"를 `vAir`로 정하고, 거리 흐림 상수는 순수 모듈(`pointStyle.ts`)에 두어 셰이더 문자열과 단위 테스트가 같은 값을 쓴다. 상단 바·스크롤 표시는 작은 클라이언트 컴포넌트(`ScrollState`)가 순수 함수(`scrollState.ts`)로 상태를 계산해 `<html data-header data-hint>`만 바꾸고 모양은 CSS가 맡는다.

**Tech Stack:** Next.js(App Router, 정적 export) · React Three Fiber · three.js 셰이더 · Vitest · Playwright(+axe)

**설계 문서:** `docs/superpowers/specs/2026-09-28-first-screen-polish-design.md` (시안 `docs/superpowers/mockups/2026-09-28-polish/`)

```ts
// 배경 점의 밝기·크기와 거리 흐림 상수(설계 2026-09-28 첫 화면 다듬기 §2.2, 시안 D).
// 셰이더(shaders.ts)는 이 값을 문자열로 박아 넣고, 단위 테스트는 같은 값을 순수 함수로 검사한다
// — WebGL 결과는 단위 테스트로 잴 수 없어서 식만 따로 뺐다(와플 FOCUS_DIM과 같은 방식).

export const POINT = { signalAlpha: 0.8, noiseAlpha: 0.117, signalSize: 0.9, noiseSize: 0.6 } as const;

// 거리 흐림: 카메라~점 거리 d가 카메라~장면 목표점 거리 dT보다 멀수록 흐리게.
// dT 기준이라 멀리 물러난 장면(검증·데모·연락처)에서도 전체가 한꺼번에 어두워지지 않는다.
// base는 ① 장면(dT ≈ 22.2)에서 시안 D(1.25 − (d − 14)/18)와 같아지도록 맞춘 값이다
export const DEPTH_FADE = { base: 0.79, span: 18, min: 0.22 } as const;

export function depthFade(d: number, dT: number): number {
  return Math.min(1, Math.max(DEPTH_FADE.min, DEPTH_FADE.base - (d - dT) / DEPTH_FADE.span));
}

// GLSL은 1을 int로 읽어 float과 섞으면 컴파일 오류가 난다 — 늘 소수점을 붙여 넣는다
export function glslFloat(n: number): string {
  return n.toFixed(3);
}
```

배경: 지금 재질은 `THREE.AdditiveBlending`(빛 더하기)이라 겹친 점이 하얗게 탄다. 재질은 하나로 유지하면서 **미리 곱한 알파 섞기**(`src = ONE`, `dst = ONE_MINUS_SRC_ALPHA`)로 바꾸고, 조각 셰이더가 `vec4(color * a, a * (1 - vAir))`를 낸다. `vAir = 0`(지형·지도·차트 점)이면 보통 섞기, `vAir = 1`(공항 불빛)이면 빛 더하기와 같다. 공항 → 지형으로 넘어가는 동안 `vAir`가 부드럽게 줄어 섞기 방식이 튀지 않는다.


을 다음으로 바꾼다.

```glsl
    float a = aKind < 0.5 ? ${f(POINT.signalAlpha)} : (aKind < 1.5 ? ${f(POINT.noiseAlpha)} * uNoise : 0.9 * uRemoved * (1.0 - uDrop));
    // 거리 흐림(설계 첫 화면 다듬기 §2.2): 장면 목표점보다 먼 점일수록 흐리게 — 지형·지도에만(차트 점은 아래 mix에서 빠진다)
    float fade = clamp(${f(DEPTH_FADE.base)} - (-mv.z - uFocusDist) / ${f(DEPTH_FADE.span)}, ${f(DEPTH_FADE.min)}, 1.0);
```

```glsl

```

를 다음으로 바꾼다.


```ts
// 스크롤 위치 → 상단 바 상태(top·hidden·peek)와 첫 화면 스크롤 표시(on·off)를 정하는 순수 함수
// (설계 2026-09-28 첫 화면 다듬기 §3·§4). 브라우저 없이 단위 테스트하려고 컴포넌트와 나눴다.

export type HeaderMode = 'top' | 'hidden' | 'peek';
export type ScrollSnapshot = { header: HeaderMode; hint: 'on' | 'off'; lastY: number; upAcc: number };

const TOP_Y = 80; // 이보다 위면 상단 바 전부(SIGNAL 포함)
const HINT_Y = 40; // 이보다 위면 SCROLL 표시
// 위로 이만큼은 올려야 다시 보인다 — 트랙패드 관성·손 떨림으로 1~2px 되돌아갈 때마다 깜빡이지 않게
const PEEK_UP = 8;

export const INITIAL_SCROLL: ScrollSnapshot = { header: 'top', hint: 'on', lastY: 0, upAcc: 0 };

export function nextScroll(prev: ScrollSnapshot, y: number): ScrollSnapshot {
  const hint = y < HINT_Y ? 'on' : 'off';
  if (y < TOP_Y) return { header: 'top', hint, lastY: y, upAcc: 0 };
  const dy = y - prev.lastY;
  if (dy > 0) return { header: 'hidden', hint, lastY: y, upAcc: 0 };
  const upAcc = prev.upAcc - dy;
  const header = upAcc >= PEEK_UP ? 'peek' : prev.header === 'top' ? 'hidden' : prev.header;
  return { header, hint, lastY: y, upAcc };
}
```

주의: 맨 위(`top`)에서 80px 이상으로 뛰어오른 경우(앵커 이동 등) `dy > 0`이라 `hidden`이 된다. 위로 조금만 움직였는데 이전이 `top`이면 `hidden`으로 둔다(80px 아래에서 `top`이 남지 않게).

```tsx
'use client';
// 스크롤을 듣고 <html data-header data-hint>만 바꾼다. 상단 바·스크롤 표시의 모양은 CSS가 맡는다
// (설계 2026-09-28 첫 화면 다듬기 §3·§4). 속성이 없으면(JS 전·없음) CSS는 맨 위 상태로 보여 준다.
import { useEffect } from 'react';
import { INITIAL_SCROLL, nextScroll } from '@/lib/scrollState';

export function ScrollState() {
  useEffect(() => {
    const html = document.documentElement;
    let s = INITIAL_SCROLL;
    let raf = 0;
    const apply = () => {
      raf = 0;
      s = nextScroll(s, window.scrollY);
      if (html.dataset.header !== s.header) html.dataset.header = s.header;
      if (html.dataset.hint !== s.hint) html.dataset.hint = s.hint;
    };
    // 한 프레임에 한 번만 계산한다(스크롤 이벤트는 프레임보다 자주 온다)
    const onScroll = () => { if (!raf) raf = requestAnimationFrame(apply); };
    apply();
    window.addEventListener('scroll', onScroll, { passive: true });
    return () => {
      window.removeEventListener('scroll', onScroll);
      if (raf) cancelAnimationFrame(raf);
      delete html.dataset.header;
      delete html.dataset.hint;
    };
  }, []);
  return null;
}
```
