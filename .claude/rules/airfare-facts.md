## 스토리 포인트
1. **"높은 R²는 좋은 모델이 아니다"를 두 번 실증.** 초기 R² 0.93은 HND_ICN에 잘못 매칭된 125만 원대 고가 행이 부풀린 값 → 무결성 필터로 0.71(MAE 약 3만 원 그대로). 직항 타당성 필터로 잘못 매칭된 경유 여정 9,387행을 걸러내자 MAE는 그대로인데 R²만 0.84 → 0.64
2. **평가 방식 3종 비교로 누수를 찾음.** GroupKFold로 train/serve 불일치(새 출발일에서 lookup 통계가 폴백값으로)를 발견, lookup 구성 4개를 각각 재튜닝해 비교
3. **예측 구간 보정.** 고정 80% 구간이 최근 구간에서 69%까지 과소 포함 → 분포 이동 외삽으로 80.2%
4. **추천 편향을 실측으로 판정.** 98% "지금 구매" 편향의 원인이 모델인지 시장인지 실제 가격 추적으로 가려냄
5. **핵심 인사이트**: "언제 사느냐"보다 "언제 떠나느냐"(공휴일·주말)가 가격을 더 크게 흔든다

## 사이트에 쓸 때 주의
- R² 0.637은 예전 수치(0.839, 0.93)와 필터 조건이 달라 분모가 다르다. "MAE는 유지하고 R² 거품을 뺐다"는 맥락으로만 비교
- 단순 기준선 MAE 48,688원과 모델 MAE 48,235원 차이가 거의 없다. 숨기지 말고 "한계와 다음 단계"에서 먼저 밝힌다
- 성능 숫자(R² 0.637·MAPE 21.4%)는 ①에 넣지 않는다(⑤에서 맥락과 함께). `0.93 → 0.71`은 "부풀려진 R² 바로잡음"처럼 이름표를 붙여 "나빠졌다"로 읽히지 않게
- 모든 수치는 재학습하면 바뀔 수 있다
