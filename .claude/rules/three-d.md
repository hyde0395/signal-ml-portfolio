# 3D 지형 규칙 (승인됨)

- **콘셉트**: B. 가격 지형(Price Landscape) + A. 플립 글자판 포인트. 실제 수집 데이터로 3D 지형 — x = 출발까지 남은 일수, z = 출발일, 높이 = 가격. U자 예약 곡선은 골짜기, 공휴일 급등은 봉우리. 플립 글자판은 수치와 섹션 제목에만
- **높이 = 노선·등급 평균 대비 %**(같은 편 기준은 공휴일 봉우리를 지워서 바꿈)
- **신호 + 잡음 두 겹**: 칸 평균 약 2,070개(밝은 점) + 칸×노선×등급 약 24,500개(흐린 점). 데이터는 대각선 띠 모양. 머리말 잡음 밭 점은 무작위 자리(`signal.ts` `buildField`)
- 3-1: 점들이 한·일 해안선 + 노선 궤적(Natural Earth 50m)을 이루다가 3-2에서 지형으로 접힘
- 공휴일 ±3일 호박색, 빈 칸 보간 없음, 9,387행은 별도 레이어(3-3에서 떨어져 나감), gzip ≤300KB

## 구조
- 화면 뒤 고정 캔버스 하나, 스크롤 위치에 따라 카메라가 챕터별 지점으로
- 점은 `Points` 하나로 그리고, 흩어지기·모이기·떨어져 나가기는 셰이더에서 계산
- 3D는 첫 화면 텍스트가 뜬 뒤 지연 로딩. 화면 밖이면 렌더 중지
- DPR 상한: 데스크톱 2, 세로 화면 1.5, 저프레임 낮춤 단계 1. 모바일 점 절반
- 30fps 미만 2초 지속 → 단계적 하향 → 정적 이미지
- 3D 청크 한도 280KB(사용자가 250 → 280KB로). 화질은 데스크톱 기준 — 줄이기 전에 사용자와 상의
- 모바일 전용 챕터별 카메라 위치·화각, 텍스트는 하단 카드
