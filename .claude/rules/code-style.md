# 코드 작성 규칙

- **코드 주석 (사용자 요청 2026-09-23)**: 코드에 한국어 주석을 단다. 파일마다 맨 위에 무엇을 하는 파일인지 한두 줄, 이유가 드러나지 않는 로직에는 "왜 이렇게 했는지"를 적는다. 코드를 한 줄씩 그대로 옮겨 적는 주석은 달지 않는다. 계획서 코드와 구현 에이전트 지시에도 이 규칙을 넣는다
- 사이트에 나오는 숫자는 코드·문구에 직접 쓰지 않고 `facts.json`에서 가져온다(`content-i18n.md`)
- 섹션 순서·번호·옆 목차는 `src/lib/sections.ts` 한 곳에서
- 검색 노출: 공개 전환 전까지 `noindex`(스위치 `src/lib/site.ts` `LAUNCHED`). 공개는 사용자가 정한다
